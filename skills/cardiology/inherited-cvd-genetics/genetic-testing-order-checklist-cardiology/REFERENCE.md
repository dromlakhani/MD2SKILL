# Reference

## ACMG v3.2 secondary-finding genes (cardiovascular), as listed in the guideline
- DCM: MYH7, TNNT2, LMNA, FLNC, TTN (truncating), BAG3, DES, DSP, RBM20, TNNC1, SCN5A
- HCM: MYH7, MYBPC3, TNNI3, TNNT2, TPM1, MYL3, ACTC1, PRKAG2, MYL2, FLNC
- ARVC: PKP2, DSP, DSC2, TMEM43, DSG2
- LQTS: KCNQ1, KCNH2, SCN5A, CALM1-3, TRDN
- Brugada: SCN5A
- CPVT: RYR2, CASQ2, TRDN, CALM1-3
- TTR amyloidosis: TTR; Fabry: GLA; Pompe: GAA
- Aortic: FBN1, TGFBR1, TGFBR2, SMAD3, ACTA2, MYH11; vascular EDS: COL3A1
- FH: LDLR, APOB, PCSK9; HHT: ENG, ACVRL1

## Japan insurance-covered CVD genetic tests (guideline Table 9)
- Simple: Fabry, Pompe, familial amyloidosis
- Complex: HCM, FH, cardio-facio-cutaneous, Costello, Osler's disease
- Extremely complex: congenital LQTS, Noonan, Marfan, Loeys-Dietz, familial aortic aneurysm/dissection, vascular and classical EDS, mitochondrial disease
- Counseling add-on fee only with a covered test, at certified institutions (2023 status).

## Variant classes
P, LP, VUS, LB, B (ACMG/AMP 2015). Disease-specific ClinGen expert panel rules exist for MYH7, RASopathy genes, LDLR and FBN1.

The guideline gives no numeric thresholds for this checklist.
